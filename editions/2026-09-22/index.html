SpaceXAI 发布 Grok 4.7，Cursor 全计划和 Copilot 同步上线

SpaceXAI（xAI 的 DBA）发布 Grok 4.7，官方称为迄今最强的编码与知识工作模型，与 Grok 4.6 同价同速：起步每百万 tokens 输入 2 美元、输出 6 美元；另提供输出约快一倍、价格加倍的 Fast 变体。官方对照表写明 CursorBench 4.0 为 46.3%（Grok 4.6 为 40.4%，GPT-5.6 Sol Max 为 41.7%，Fable 5.1 Max 为 51.8%），Terminal-Bench 4.0 为 38.0%（Grok 4.6 为 20.3%），DeepSWE v1.1 高推理强度为 71.0%。

官方称它换了比 4.6 更大的新基座，并做了更长、更偏向多小时任务的强化学习，补充训练含匿名化 Cursor 工作流数据；同时训练它原生理解 Grok Bot harness，并换上一套新的 safeguard 栈。模型卡写明：可通过 console.x.ai 调用；是 Grok Build 以及 Word / PowerPoint / Excel 插件的默认模型；对 Cursor 全计划开放；也可经 OpenRouter、Vercel、Cloudflare、Snowflake、Databricks Mosaic 等网关使用。消费级网页、手机和 X 上的 Grok 计划稍后上线。

GitHub Changelog 同步写明：Grok 4.7 正在向 Copilot Pro / Pro+ / Max / Business / Enterprise 滚动上线，按供应商目录价计费；企业或商业管理员可在模型策略里开关，默认开启新模型，除非关闭全局默认或单独禁用。

适用范围：
  • 对照数字是官方自评，未独立复现。
  • 消费级 grok.com / 手机 / X 尚未上线；Copilot 是逐步开放，页面写明暂时看不到属正常。
  • 模型卡写明预训练数据截止 2026 年 6 月，补充训练用到晚至 8 月的生成数据；不用于无人值守的高风险医疗、法律、金融或安全关键决策。
  • 未实测 Cursor、Grok Build、API 或 Copilot 中的实际表现。

加州州长签署七项数据中心法案，要求自担电网与用水成本

路透社报道：加州州长 Gavin Newsom 周一签署七项法案，对快速扩张的数据中心提出电费、用水和地方监督新要求，目的是避免新建发电与电网升级成本转嫁给其他用户。KQED 与地方媒体列出法案为 AB 1577、AB 2383、AB 2469、AB 2619、SB 886、SB 887、SB 1168。

报道写明：SB 886 与 AB 2383 要求公用事业委员会为数据中心制定新电价，覆盖接网与供电成本；AB 2469 要求披露预计用水后地方才能批准；SB 887 阻止数据中心跳过州环境审查。Newsom 声明称，这些法律确保加州人仍坐在驾驶座上，不让从数据中心获利的一方把代价转给居民。

适用范围：
  • 这是已签署的州法，具体费率和执行细则仍取决于公用事业委员会与地方落实。

  • Data Center Coalition 称要求可能重复，会令加州对数据中心更缺乏吸引力；这是行业表态，不是法律文本。
展开：背景与补充
