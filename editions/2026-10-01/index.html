Google 发布 Gemini 4 Argon：先只给受信任的网络防御者，输出上限提到 100 万 token

Google 于 2026 年 9 月 30 日宣布 Gemini 4 Argon。发布页写，它现在通过 Fairwind 计划向一组受信任的网络防御者推出，同时参与美国政府发布前的自愿访问流程；护栏继续加强后，再向开发者、企业和消费者开放，先从付费 API 客户和 Google AI Ultra 订阅用户开始。页面没有把今天写成已经对公众或普通开发者开放。

页面写，推出时的介绍价为每百万输入 token 2 美元、每百万输出 token 10 美元，缓存输入比输入价低 95%。脚注只写介绍期结束后改为每百万输入 4 美元、输出 20 美元，没有写介绍期到哪一天结束，也没有写 Fairwind 访问今天是否按这个价格计费。输出 token 上限从之前的 6.4 万提高到 100 万。页面没有单列上下文窗口。

页面写，对受信任的防御者和 Google 内部团队，Argon 会在没有网络护栏的情况下提供，以便使用完整的防御能力。对更广泛的滥用，页面写模型会拒绝网络以及化学、生物、放射和核方面的有害请求，并称在 Gray Swan 的间接提示注入基准上领先，没有给出分数。Wiz 的 Scan for Good 被写成早期例子：模型发现了一处此前前沿模型没发现的、会暴露医疗软件中敏感个人信息的严重漏洞，但没有给出软件名称或漏洞编号。

加州命令本州机构继续称 AI，并签署一批职场与透明法案

加州州长办公室于 2026 年 9 月 30 日公布新闻稿，并链接已签署的行政命令 N-10-26。命令写，受州长权限约束的机构和部门应把 Artificial Intelligence 和 AI 称为 Artificial Intelligence 和 AI，尽管联邦政府使用了重新命名或不同的术语；与法律不一致时除外。命令写明立即生效，并写明不创设任何可对加州或其机构、人员执行的实体或程序权利。

同一篇新闻稿列出同日签署的法案短标题，其中包括 AB 1331 职场监控、AB 1864 基因合成设备的制造者和提供者、AB 1883 职场监控工具、AB 1979 与 SB 503 医疗服务中的人工智能、AB 2392 公立高等院校生成式人工智能的采购标准和培训、AB 2713 与 SB 1000 加州人工智能透明法案、SB 574 律师与替代性争议解决、SB 947 就业中的自动决策系统、SB 951 技术性替代的通知、SB 1111 数字复制品，以及 SB 1159 人工智能的透明与治理。加州劳工联合会主席的话把 SB 947、SB 951、AB 1331 和 AB 1883 称为这四项职场法案。

新闻稿用条目概括效果：雇主不能只依靠人工智能做纪律处分或解雇；大规模裁员、搬迁或终止若由人工智能系统造成，雇主须告知；禁止在工作场所的浴室使用职场监控工具；加州公立高等院校须为学生、教师和职员建立人工智能培训；律师不能把起草书状或法律判断这类核心法律工作完全交给人工智能。基因合成一条写，要求相关公司遵循安全指南、核验客户，并检查送出的遗传物质。这些是新闻稿的概括，不是章程原文。

适用范围：
  • 命令只约束州长权限下的机构和部门，并写明与法律不一致时除外。它不创设可执行的权利，也不是国会立法。

DeepMind 提出 SynthID Bio：给 AI 设计的蛋白质加水印，湿实验里称功能仍在

GitHub 把 HydraFusion 放进 VS Code 和 Copilot 应用，仍是研究预览

GitHub Changelog 于 2026 年 9 月 30 日写明，HydraFusion 研究预览现已进入 Visual Studio Code 和 GitHub Copilot 应用，此前只在 Copilot CLI。它出现在模型选择器里，但不是单一模型，而是编排多个模型。页面写，它用推理、代码生成、调试和工具使用的能力信号选择执行方式，并有三种工作流：Single 由一个模型直接完成；Cascade 由较省的模型起草，再由质量门决定接受或升级到更强模型；Critique 由一个模型起草，另一个模型家族的只读批评者复查，起草模型再修改一次。

VS Code 需要 1.140 或更高版本，或 VS Code Insiders；选择器里没有时，可打开 chat.copilot.hydraFusion.enabled。组织或企业账号可能要管理员允许预览功能。Copilot 应用需要更新到最新版，并在设置中打开 HydraFusion。可用范围是 Copilot Pro、Pro+、Business 和 Enterprise；Business 和 Enterprise 必须由管理员启用预览功能。页面写它仍是研究预览，可能改变。这次还增加了步骤透明度和更频繁的进度更新。Auto 为每次请求选择一个模型；HydraFusion 则在同一轮里选择工作流并协调多个模型。

适用范围：
  • 未在 VS Code 或 Copilot 应用里打开选择器。质量门的阈值、可选模型名单和是否另计费，这篇更新日志没有写。
  • 这是研究预览，不是一般可用。组织策略可以不打开它。
