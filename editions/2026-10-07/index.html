OpenAI 公开 722 篇数学手稿：内部模型还没发布，未形式化的结果可能有问题

OpenAI 新闻源的时间是 2026-10-06T12:00:00+00:00。公告写，公司发布一批由内部前沿模型做出的新数学结果。为安排披露方式，公司咨询了普林斯顿高等研究院独立的数学与人工智能咨询小组，并称这次发布参考了该小组的建议和公开推荐。结果放在 GitHub 仓库 openai/math，附有修订和引用的规则。博客写，许多证明会以 Lean 形式化放进仓库，并会继续补充；同时公开 10 份模型推理的缩写摘要、按 ChatGPT Pro 用量估算的计算，以及尝试过的题目数量。平均每个结果用了大约三小时 ChatGPT Pro thinking 的计算。做出这些结果的模型这次没有发布。公司还写，将资助一系列工作坊、会议和专项来理解人工智能做出的重要结果，细节以后再说。

页面写，ML4 是 1 万亿参数的原生多模态模型，每个 token 激活 490 亿参数，是该公司迄今最大的模型。它在 Mistral 位于欧洲的自有数据中心、3800 张 NVIDIA Grace Blackwell GPU 上从零训练，公开预览也由这套基础设施提供。训练数据里有相当一部分是多语言，覆盖 160 多种语言，包括欧盟每一种官方语言。提供范围包括由 Mistral 端到端运营、不依赖其他数字服务提供商、并受欧洲法律约束的欧洲部署。页面没有写预览接口的价格。

Anthropic 把网络验证计划扩成三档，合格防守者可以申请更少拦截

Anthropic 新闻稿的日期是 Oct 6, 2026，页面没有钟点。公司扩大 Cyber Verification Program，向合格的安全人员提供更强的网络能力和更少的拦截。计划收成三档，每档都包含 Claude Opus 5.5、Claude Sonnet 5.5、Claude Mythos 5.1，以及以后的新模型。一般可用的模型仍然对大多数网络工作做保守拦截。过去六个月的 Project Glasswing 和原来的 CVP 被并进这一套。

Defense Access 面向防守，包括安全运营、事件响应、恶意软件逆向，以及分析和验证漏洞。公司写，预期多数做防守工作的机构能够通过，目标是几天内回复。Red Team Access 在此之上增加已经获授权的渗透测试和红队，目前只对机构开放，个人研究者不能申请；审查预计要几周，等待期间先进入 Defense。这一档仍会实时拦截可能造成人身伤害或大范围中断的行为，例如部署勒索软件、破坏物理系统，或对高风险安全系统做渗透测试。Specialized Access 拦截最少，留给经过核实、被授权测试可能影响生命或扰乱市场的系统的少数机构，例如飞行操作系统、电网、电信网络、银行间转账和政府行政网络。这一档目前与美国政府一起逐家审查。现有 Project Glasswing 成员转入这一档，当前模型不必重新审批。

效果测试用 Claude Opus 5.5 跑 CyScenarioBench，10 道题各试 5 次。没有 CVP 时，每道题都在第一条提示被拦截。Defense 档 50 次里有 46 次中途被拦截，4 次完成。Red Team 档没有拦截，完成 34 次；页面称这与不加防护时 67.6% 的完成率相当，并用这个完成率代表 Specialized。

Project Glasswing 的伙伴在 2026 年 4 月到 7 月至少发现 12.9 万个已经核实的软件漏洞。Anthropic 自己的开源扫描在 4 月到 10 月另发现 5500 个。其中已有超过 3.3 万个被标为严重或高危。页面写，这是部分伙伴调查的下限，依据是 33 份伙伴报告里的部分数据，真实影响预期至少再高五倍。加入计划的机构必须保留数据，以便监测滥用。Enterprise Frontier Safeguards 要到今年秋天晚些时候才提供。在此之前，已经对 Claude Fable 5.1 或 Claude Mythos 5.1 使用零数据保留的机构，也可以在 CVP 里使用零数据保留。CVP 可以在 Claude Platform、Google Cloud Vertex AI 和 Microsoft Foundry 使用。Amazon Bedrock 只提供给有资格使用 Enterprise Frontier Safeguards 的客户。

OpenAI 公开测试 Decisions API，目前只接 gpt-6-luna

OpenAI API 更新日志把这项写在 October 2026 的 Oct 6：Decisions API 以公开测试版配合 gpt-6-luna 发布，端点是 POST /v1/decisions。指南写，公开测试预计未来数周转为正式版，目前只有 gpt-6-luna 可以用。指南称，它把文本和图像变成程序能直接用的判断，大约比 Responses API 快 10 倍。这是文档里的速度说法。

一次请求有三部分：模型、共享输入、问题列表。输入可以是一段文本，或同时包含文本和图像的用户消息。图像必须是内联的 base64 data URL，不接受托管的 HTTP 或 HTTPS 图片地址，也不接受 file_id。问题分三类。predicate 返回条件成立的概率，范围是 0 到 1。choice 从调用者给的选项里选一个，并返回各选项的概率和单独的 confidence。score 按从低到高的等级做概率加权平均，分数可以落在两个等级之间。指南写，如果要的是自定义 JSON 对象或工具调用，仍用 Responses API。

gpt-6-luna 在这个端点上的输入价格是每 100 万 token 0.10 美元，只对输入 token 收费，没有缓存读写费用，也没有输出 token 费用。区域处理和长上下文的乘数另计。符合条件的客户可以使用零数据保留和 HIPAA。数据驻留和区域处理支持美国，以及欧洲经济区加瑞士。没有调用这个端点。

  • 快 10 倍是文档相对 Responses API 的说法，没有在本机计时。
  • 同一天日志里把 API 用量档收成三档，是另一项变更，不在这个接口的行为里。

Sierra 与 Meta 宣布个人代理协议，v0.1 规范本月稍后才发布

Sierra 博客由 Bret Taylor 和 Clay Bavor 署名，页面日期是 October 6, 2026，正文没有钟点。他们宣布 Personal Agent Protocol，称这是 Meta 和 Sierra 正在与 Genesys、Instinct、Rocket、Shopify、Stripe、Walmart 一起制定的开放标准，用来规定个人代理如何与企业交互。目标是处理认证、由消费者决定授权，并让公司看见代理通过网站、API 或公司自己的代理做了什么。任何人都可以实现。v0.1 规范计划本月稍后发布，同时会办设计工作坊，并放出参考实现。更细的权限、航班或订单的推送通知，以及不交出信用卡号的支付扩展，写在后续，不是今天已经发布的文本。

页面写，会话基于 OAuth。代理先在公司网站上发现对方提供什么、怎么接通，再代表用户开始一次会话。可以先做访客，用来查库存或退货政策。需要账户时，用户在公司页面登录，或使用已经交给个人代理的凭据。用户决定代理是只读还是可写。登录前的问题和登录后的改单属于同一次访问。公司可以选择三条通路：普通网页、基于 MCP 和 OpenAPI 的 API，或公司自己的对话代理。
