GPT-6 Cyber 发布，ExploitGym 升到 48.5%

OpenAI 发布 GPT-6 Cyber，先向部分 Daybreak Red 客户开放。ExploitGym 从 32.1% 升到 48.5%。不加部署提示时，99.93% 的测试没有越出指定范围。网络安全定为 Critical。

限定：分数和漏洞数量都是 OpenAI 自己的统计。

原文 · OpenAI
详细与核验

页面写 ExploitGym 上 GPT-6 Cyber 为 48.5%，GPT-5.6 Cyber 为 32.1%，并称相对提升约 51%。新的网页渗透测试里，模型看不到源代码，GPT-6 Cyber 的漏洞召回是 40.3%，GPT-6 Astra 是 32.0%。页面写它在多数网络安全任务上超过 GPT-6 Astra，即便 Astra 没有拒绝请求。准备度框架把 GPT-6 Cyber 的网络安全定为 Critical，GPT-5.6 Cyber 此前是 High。

页面写研究者用 GPT-6 Cyber 在 Linux 上做出 948 个提权利用，并复现 1724 个漏洞。同一套研究工具下 GPT-5.6 Sol 做出 166 个利用。已向维护者披露 304 项关键发现，并附上候选补丁。Firefox 方面，它为 81 个被 Mozilla 定为高严重性的新漏洞提供了证据和可复现测试，并显示另外 30 个已知问题比原先报告的更严重。Mozilla 已经开始合入修复。

GPT-6 Cyber 先通过 API 和 Codex 向部分已获批的 Daybreak Red 客户提供。页面写随后会扩到全部 Daybreak Red 客户，并把 GPT-5.6 Cyber 开放给全部 Daybreak Red 客户。新设的组别叫 Daybreak Red for Critical Infrastructure，给获批的关键基础设施防御方保留授权测试的权限。

  • 目前只向部分已获批的 Daybreak Red 客户开放，入口是 API 和 Codex。

百度公开 ERNIE 5.5 Flash Base 的预训练权重。总参数 2800 亿，每 token 激活 140 亿，预训练用了 33.5 万亿 token。权重在 Hugging Face，后训练版本还没发布。
