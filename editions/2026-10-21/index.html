Meta 暂停 Muse 的对话分享

Meta 暂停了 Muse 的对话分享。Claroc 在被动 DNS 里看到 6800 多个分享主机名，对话标题就写在域名里。发言人说先停掉这项功能，再看怎样减少这些链接被找到。

限定：暂停的是分享链接，不是整个 Muse。已进被动 DNS 的标题仍可能留在记录里。

原文 · The Verge
详细与核验

The Verge 写，Meta 发言人 Tracy Clayton 在邮件中说，用户可以分享特定 Muse 产物，从而生成一个持有链接的人能够打开的页面。公司已暂停这项功能，以便审阅这份报告，并考虑如何改变这些链接被发现的方式。

Claroc 写，过滤被动 DNS 扫描噪声后，cf.metaaiusercontent.com 下剩下 6800 多个分享主机名。主机名由对话标题加一段随机 ID 组成，从主机名可以拼回链接。他们只打开了其中几百个，看到营销公司的收入回顾、小企业贷款申请、全年员工日历，以及求职者与一家 AI 实验室通话的笔记。

Claroc 在 10 月 20 日的更新写，Ars Technica 当天报道后，Meta 告诉 Ars 正在暂停该功能。Claroc 复查了本月早些时候不登录就能打开的 40 个分享，现在都打不开，提供内容的主机名返回错误。主机名和标题仍留在被动 DNS 历史里。

Ars 写，Claroc 联合创始人 Asaf Aprozper 说，10 月 8 日已通过 Meta 的漏洞赏金提交，也在 LinkedIn 联系过，当时没有收到回复。暂停是 Ars 询问之后 Meta 给出的。

适用范围：
  • 6800 多个是 Claroc 过滤噪声后的主机名数量，不是 Meta 公布的数字。他们只打开了其中几百个。
  • 分享页是用户自己要求 Muse 生成的。不登录就能打开，是 Claroc 描述的产品设计。
  • 10 月 8 日提交赏金后没有回复，只有 Claroc 联合创始人的说法，页面没有附上赏金回执。
展开：背景与补充
  • Claroc 把能从被动 DNS 拼回的分享页叫 GhostShares。文中也提到 ChatGPT、Claude 和 Grok 以前出现过分享内容被搜到的事，那不是这次的新事实。

Google 宣布 TorchTPU 开源

Google 在 PyTorch Conference 上宣布 TorchTPU 开源，让 PyTorch 能在 TPU 上训练和部署。公司称现有工作只需很少的代码改动。Hugging Face Transformers v5 已能直接把模型放到 TPU。

限定：仓库 3 月就已创建。这次宣布的是可以当开源原生栈使用，不是新建仓库。

原文 · Google Cloud Blog
详细与核验

Google Cloud 博客的日期是 2026-10-20。正文写，在 PyTorch Conference 2026 上宣布 TorchTPU 现已在 GitHub 开源，仓库是 google-pytorch/torch_tpu。TPU 成为 PyTorch 里与 GPU、CPU 并列的原生选项，可以训练、服务和部署。

博客写，TorchTPU 与 Meta 的 PyTorch 团队合作。现有 PyTorch 工作负载可以用熟悉的 API 在 TPU 上运行，代码改动很少。可以先用 eager 模式调试，再用 torch.compile 转到生产性能。

博客写，与 Hugging Face 合作后，Transformers v5 把模型部署到 TPU 时传入 device_map="tpu" 即可。Diffusers 在 TPU 上支持 eager、torch.compile 和张量并行。

博客写，vLLM 的 TorchTPU 后端支持连续批处理、量化和多芯片并行，并称不需要改现有推理栈。SGLang 的 TorchTPU 后端保留上游 worker、调度器和 API 服务器。TPU agent suite 在 GitHub 上处于 preview，用来协助迁移、诊断和推理调优。

适用范围：
  • google-pytorch/torch_tpu 的 created_at 是 2026-03-09T16:59:42Z，pushed_at 是 2026-10-20T23:58:00Z。本期新事实是博客宣布它可以作为开源原生栈使用，不是今天新建仓库。
  • 代码改动很少，以及 vLLM 不需要改现有推理栈，都是这篇博客的说法，页面没有给出对照实验。
  • TPU agent suite 仓库创建于 2026-10-16T20:13:31Z。博客现在把它标为 preview。

Claude 设计的蝎毒结合蛋白有 17 个通过实验

Anthropic 用内部研究模型设计了针对蝎毒的结合蛋白。两家实验室测了 211 个设计，17 个达到结合标准。最强的两个对 Cn2 的结合在个位数纳摩尔，设计和数据已经公开。

限定：只测了重组毒素的结合，没有做细胞中和或动物实验。

原文 · Anthropic
详细与核验

Anthropic 研究页写 Published Oct 20, 2026。datePublished 是 2026-10-20T00:00:00.000Z，dateModified 是 2026-10-20T16:04:01.000Z。他们让一个内部研究模型设计针对蝎毒神经毒素的 minibinder。提示词和四次后续与 Citrini Research 一起写。

Adaptyv Bio 和 Twist Bioscience 实验测试了 211 个设计的结合。其中 17 个达到标准，而且每个只针对一种毒素。针对多种毒素的设计，没有一个对多于一种毒素达标。

达标要求两个实验室都命中、每次重复都看到结合、每个 KD 达到 1 µM 或更紧，并且对无关蛋白 CLEC12A 没有信号。最强的两个 Cn2-B1 和 Cn2-B2 针对墨西哥蝎 Centruroides noxius 的 Cn2，两边都测到个位数纳摩尔的 KD。

页面写没有在细胞环境或活体动物里测试中和或效力。竞争实验提示它们与已报道能在小鼠中中和 Cn2 的抗体 LR 靠近同一表位，因此页面推测可能中和 Cn2，但这不是实测。实验用的是重组毒素，不是从毒液纯化的毒素。

页面写 Claude 用 12 个设计工具生成 318484 个设计，共折叠筛选 553052 个设计与毒素的配对。第一次提示后 64 小时给出 180 个设计，这次活动大约用了 1 万 GPU 小时。211 个设计和结合数据公开。

适用范围：
  • 17 个达标设计每个只对一种毒素有效。多毒素设计没有一个对多于一种毒素达标。
  • 没有细胞中和实验，也没有动物效力实验。和抗体 LR 的竞争只说明结合位置可能接近。
  • 测试的是重组毒素，不是从毒液里纯化的毒素。1 万 GPU 小时和 64 小时都是页面给出的数量，不是独立复现。

  • 页面写蝎子每年蜇伤 120 万人以上、死亡超过 3250 人。这是背景，不是这次实验的结果。
  • 8 月他们发表过一次单提示词的蛋白设计。这次新的是蝎毒神经毒素、两家实验室的结合测试，以及公开的 211 个设计。
