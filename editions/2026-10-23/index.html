原文 · OpenAI API
详细与核验

OpenAI 的 Decisions 指南现在写，The Decisions API is now generally available。端点仍是 POST /v1/decisions，目前唯一支持的模型仍是 gpt-6-luna。指南仍称返回速度大约比 Responses API 快 10 倍。这是文档里的说法。

指南列出公开测试之后新增的能力：共享输入可以走提示缓存并获得缓存折扣；每个问题可以自带图片；可以用 input_json 直接传入 JSON；单次问题上限从公开测试的 200 提到 400；图片除了内联 base64，也可以用公开的 HTTP 或 HTTPS 地址；可以按顺序评估消息、函数调用和工具输出；可以查看组织用量；GPT-Live 可以直接调用 Decisions，或在输入、输出转写到达时触发。文件、音频和条目引用不能作为这个端点的输入。

指南写，gpt-6-luna 未命中缓存的输入是每 100 万 token 0.10 美元。缓存读取有折扣，缓存写入要收费，费率与 gpt-6-luna 的标准提示缓存相同。不对输出 token 收费。

TechCrunch 的 datePublished 是 2026-10-22T19:00:00+00:00。产品负责人 Nikunj Handa 对 TechCrunch 说，速度从一两秒到三秒缩到 100、120、180 毫秒。Speak 的 CTO Andrew Hsu 说，动作间隔从 1.4 秒降到 0.13 秒。稿件写周四向全部客户开放，并点名 Box、Datadog、Ramp 和 Speak 的试用。这些数字和客户名只来自这篇采访。
