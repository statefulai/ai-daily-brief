tandem.cpp 把放不下的 MoE 专家留在内存里

ewhacc 放出独立于官方的 llama.cpp 补丁 tandem.cpp。放不进显存的 MoE 专家留在内存，常用的留在显卡。作者用一台 4090 测 Qwen3.8-Flash-Next，贪心解码从 29.8 提到 97.3 token 每秒。

限定：速度来自作者在一台 4090 上的自测。

原文 · GitHub
详细与核验

GitHub 仓库 ewhacc/tandem.cpp 创建于 2026-11-01T10:04:25Z，最近推送 2026-11-01T19:53:06Z。接口显示 3 个星。README 称它是 llama.cpp 的补丁集，与 ggml-org 无关，基线提交是 f5222f25c，README 写该提交日期为 2026-10-28。

README 称它把最常用的 MoE 专家留在 GPU，其余交给 CPU 计算，适用于 llama.cpp 能跑的 MoE 模型。目标是单用户解码。

README 的表写，一台电脑（i5-12400F、64 GB DDR4、RTX 4090）上跑 GSM8K，Qwen3.8-Flash-Next IQ3_S 加 MTP，贪心解码结果是 llama.cpp 29.8 tok/s，tandem.cpp 97.3 tok/s（3.3 倍），Strata 精确模式 103.6 tok/s。gpt-oss-120b 贪心解码：llama.cpp 27.8 tok/s，tandem.cpp 51.5 tok/s（1.85 倍）。

README 写调优只针对 Qwen3.8。显存放不下的其他 MoE（gpt-oss-120b、GLM-4.5-Air、Qwen3.6-35B-A3B、DeepSeek-V4.1）通常是 1.4 到 2.1 倍。64k token 提示的预填充是 1.4 到 1.8 倍。Strata 默认会跳过低排名专家，更快但是近似，同一 Qwen 设置下 README 写 127.1 tok/s。这些数字都是仓库作者给出的，不是第三方复测。

适用范围：速度表只覆盖作者写下的那台 4090 电脑和 GSM8K 解码，调优只针对 Qwen3.8。

展开：背景与补充
  • Strata 在同一张表的精确模式是 103.6 tok/s。README 写它的默认近似模式是 127.1 tok/s，那一档会跳过部分专家。
