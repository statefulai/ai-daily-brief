Windows 11 上的执行容器正式可用，Copilot 本地沙箱同时转正

Pavan Davuluri 的 Windows 博客写 published October 7, 2026，没有钟点。Microsoft Execution Containers（MXC）今天在 Windows 11 上正式可用。组织可以规定智能体能访问哪些文件和网络，策略在运行时执行。个人电脑上，这些限制做成智能体体验的一部分。博客写，MXC 不只有 Windows，但 Windows 上可以从进程和会话隔离做到 WSLc、虚拟机和 Windows 365 for Agents。

博客列出已经支持 MXC 的有 OpenAI 的 Codex、GitHub Copilot、OpenClaw、Replit、LM Studio、英伟达 OpenShell 和 Unsloth AI。写成即将支持的有 Anthropic Claude Code、Box、Egnyte、Heidi Health、Nous Research 的 Hermes Agent、Manus、Perplexity、Raycast 和 Simular。Meta 的 Muse for Windows 写成即将作为带 MXC 的原生应用出现，不是今天已经可以安装。

GitHub Changelog 的时间是 2026-10-07T15:46:17+00:00。Copilot 的本地沙箱在 Copilot CLI、Copilot 应用，以及使用 Agent Host 的 VS Code 会话里正式可用，不另收费。沙箱由 MXC 把同一套策略翻译成 Windows、macOS 和 Linux 的系统控制。可以限制智能体命令能读写的文件和目录，控制互联网、本地网络、Git 凭据和 GitHub CLI 凭据，并在支持的地方覆盖本地 MCP 和语言服务器。企业设置可以强制打开沙箱，开发者不能把策略放宽。模型在哪里运行，和工具被隔离到哪里，是两件事。策略管的是工具执行，不随所选模型改变。

同一篇 Windows 博客写，Build 时介绍的 MAI Code 1.1 Flash 总参数 1370 亿、激活 68 亿。今天把它放到本机，用 3-bit 把体积减少近 80%，并在本地使用 256K 上下文。GitHub HydraFusion 调用本机模型，写成 10 月晚些时候才在 Copilot 应用、CLI 和 VS Code 做实验性预览。llama.cpp 写进 Windows ML，是今天宣布的。Copilot 在 Copilot+ PC 上读取本机内容、在本机做动作和调用本机模型，写成未来数月才开始，而且要用户允许。Windows Search 里直接执行的新动作，今天起向实验通道的 Windows Insider 推出。
