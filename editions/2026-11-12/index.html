Google 放出 Gemini Decisions API，输入价每百万 token 0.10 美元

Google 放出 Gemini Decisions API，模型 ID 是 gemini-decision-1。一次最多评 1000 道封闭题，输入每百万 token 0.10 美元，输出不计费。开发者已可用 Google AI Studio 的密钥调用。

限定：150 到 250 毫秒和近 5 倍价差，是谷歌自己的对照。

原文 · Google
详细与核验

Google 博客的发布时间是 2026-11-11T18:00:00+00:00。页面宣布 Gemini Decisions API，模型名 Gemini Decision 1，模型 ID 是 gemini-decision-1。

一次请求最多带 1000 个独立问题，题型包括是非、2 到 255 个选项的选择，以及从 0 起算的有序量表。输入可以是文本、图像、音频、视频和 PDF，上限 256K token。每个答案带 0 到 1 的置信度。

页面写价格是每百万输入 token 0.10 美元，输出 token 不计费。端到端延迟写成 150 到 250 毫秒，模型计算的中位延迟写成 50 到 100 毫秒。

页面写，在共享基准上，Gemini Decision 1 配 Decisions API 比 Gemini 3.5 Flash-Lite 配 Interactions API 便宜近 5 倍。

页面写开发者可以在 Google AI Studio 取 API 密钥，并有 Python、JavaScript 和 REST 文档。

适用范围：延迟和近 5 倍价差是博客里的公司数字，本期没有复测。

展开：背景与补充
  • OpenAI 的 Decisions API 已在 10 月 7 日和 10 月 23 日正刊写过。那是另一家公司的接口，当时只接 gpt-6-luna。这次是谷歌自己的模型和标价。

DeepMind 发布 AlphaGenome 2，免疫细胞因果变异检出 30%

DeepMind 发布 AlphaGenome 2，用来预测 DNA 变异在具体细胞类型里如何改变基因表达。TenK10K 的 28 种免疫细胞上，因果变异检出是 30%，上一代微调后是 16%。非商业研究已可走 AlphaGenome API。

限定：30% 对 16% 是公司在 TenK10K 上的结果。商业用途仍是私人预览。

原文 · Google DeepMind
详细与核验

DeepMind 博客的发布时间是 2026-11-11T15:00:00+00:00。当天宣布 AlphaGenome 2，按具体细胞类型预测 DNA 变异对基因表达的影响。

页面写，相对上一代最好模型，AlphaGenome 2 识别出近两倍会改变细胞中基因表达的变异。训练用了超过 1 亿个单细胞图谱，覆盖 68 种组织。后文写训练数据包括人和小鼠、超过 1.07 亿个单细胞图谱。

在 TenK10K 的 28 种原代免疫细胞上，因果变异检出是 30% 对 16%，方向性基因效应是 43% 对 23%。对照是在单细胞数据上微调过的原版 AlphaGenome，以及其他专用工具。

非商业研究从当天起可通过 AlphaGenome API 使用。商业研究是私人预览。页面写两代模型只供研究，没有经过临床或诊断批准。

页面写 Google Antigravity 里的 AlphaGenome 2 Skills 会稍后放出，宣布当天还没有。

适用范围：
  • 非商业研究可经由 AlphaGenome API。商业研究是私人预览。
  • 未批准用于临床或诊断。
展开：背景与补充
  • The Verge 引 Žiga Avsec 说，AlphaGenome 2 短期内不会换掉上一代，因为更细的预测更贵。9 月那份覆盖人类基因组每个单字母变化的图谱，仍是用上一代做的。

美联航限制第三方 AI 助手代客订票

美联航周三起限制未经授权的第三方个人 AI 助手代客订票。公司称，把账号交给这类助手可能泄露资料、买错票或动用里程。值机还可能违反联邦行李声明规定，公司会同时更新订票和出票政策。

限定：助手仍可展示航班，但不能代为完成交易。

原文 · CBS News
详细与核验

CBS 写美联航于周三表示，禁止人工智能代理代表旅客预订航班。文章发布时间是 2026-11-11T14:37:38-05:00。

CBS 引美联航的话：把账号凭据交给个人的第三方 AI 助手，可能暴露敏感信息，这些工具的操作可能导致未打算的购买、账号变更，或使用 MileagePlus 里程。

CBS 引美联航：将在自己的数字平台上直接限制，并通过旅行社和聚合商间接限制，禁止未经授权的第三方个人 AI 代理或助手使用。公司正在更新订票和出票政策。

CBS 写，用 AI 代理值机可能违反联邦规定，包括旅客须当面确认行李不含违禁物。

The Verge 同题文章的发布时间是 2026-11-11T21:54:21+00:00。它写，代理仍可向用户展示美联航航班，但不能代为完成交易。
